# ✈️ Lets Go Yatra

### Premium Travel Agency Website Experience

A modern, luxurious, and fully responsive travel agency website designed for **Lets Go Yatra**, Hyderabad.  
Built with cinematic visuals, smooth animations, glassmorphism UI, and conversion-focused sections to create a premium travel booking experience.

# 🌍 Overview

Lets Go Yatra is a high-end travel agency frontend experience crafted to inspire travelers and increase customer inquiries through elegant UI/UX and immersive storytelling.

The website includes:
- Luxury hero sections
- Destination showcases
- Premium tour package cards
- Responsive layouts
- Smooth animations
- Modern glassmorphism UI
- Travel search interface
- Conversion-focused CTA sections

# 🚀 Run Locally

## Prerequisites
Make sure you have installed:

- Node.js
- npm or yarn

---

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/lets-go-yatra.git
```

---

## 2️⃣ Navigate to Project Folder

```bash
cd lets-go-yatra
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

---

## 4️⃣ Start Development Server

```bash
npm run dev
```

---

# 🔑 Environment Variables

Create a `.env.local` file in the root directory:

```env
VITE_GEMINI_API_KEY=your_api_key_here
```
